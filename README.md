# 📊 Customer Churn Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Customer Churn Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes customer churn and retention patterns across different customer demographics, contract types, internet services, payment methods, tenure, partner status, and dependent status.

This project was completed as part of a task provided by **SaiKet Systems**, helping me strengthen my practical skills in data analytics, data visualization, and business intelligence.

---

## 🎯 Objective

The main objective of this project is to analyze customer churn and identify patterns that can help businesses understand:

- How many customers are leaving the company
- Overall customer churn rate
- Customer retention patterns
- Churn across different contract types
- Churn based on internet service
- Churn based on payment methods
- Customer distribution by demographics
- Relationship between customer tenure and churn
- Customer behavior based on partner and dependent status

## 📊 Dashboard Overview

The dashboard provides an interactive view of customer churn and retention.

### 🔹 Key Performance Indicators

The dashboard includes the following major KPIs:

- **Total Customers:** 7.043K
- **Churned Customers:** 1.869K
- **Churn Rate:** 26.54%
- **Average Tenure:** 32.37 months

## 🎛️ Interactive Filters

The dashboard includes interactive slicers that allow users to filter the analysis based on:

- Gender
- Contract
- Internet Service
- Payment Method
- Senior Citizen
- Tenure

These filters make it easier to perform targeted customer analysis.

---

## 💡 Key Insights

Some important observations from the dashboard include:

- The overall customer churn rate is approximately **26.54%**.
- Month-to-month customers show a substantially higher churn rate compared with customers on longer-term contracts.
- Churn varies across different internet service categories.
- Payment method is also associated with different churn patterns.
- Customer tenure provides useful information for understanding retention behavior.
- Demographic and household characteristics can be explored using the interactive filters.

> These insights are descriptive observations from the dashboard and should be interpreted together with the underlying customer data.
